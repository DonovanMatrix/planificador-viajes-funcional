# Análisis Funcional

## Dataclass
Se utilizó la clase Viaje para representar cada viaje registrado por el usuario.

## Lambda
Se empleó para ordenar viajes y realizar operaciones de filtrado.

## Map
Se utilizó para obtener los presupuestos de todos los viajes registrados.

## Filter
Permite mostrar únicamente los viajes económicos.

## Reduce
Se utilizó para calcular el presupuesto total de todos los viajes.

## Closure
Se implementó mediante la función crear_descuento(), que genera funciones de descuento personalizadas.

## Match/Case
Permite generar recomendaciones según el tipo de viaje seleccionado.
